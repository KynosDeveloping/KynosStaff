## KynosStaff — Source Code

[DOCUMENTATION](https://kynosdeveloping.gitbook.io/kynosdeveloping/kynosstaff)

Full source code release of KynosStaff, a Paper/Spigot staff management plugin built on top of KynosLib.

### 📋 Requirements
- Java 21+
- Paper/Spigot 1.21+
- [KynosLib](https://github.com/KynosDeveloping/KynosLib) (required dependency)
- Maven (to build)

### 🔧 Build
```bash
mvn clean package
```

The compiled JAR will be in `target/`.

---

### What's included
- All Java source files under `src/main/java/`
- Resource files: `plugin.yml`, `config.yml`, `lang.yml`, `settings.yml`
- Maven project structure ready to import in any IDE

> ⚠️ This is the raw source. If you just want to install the plugin on your server, download the precompiled JAR instead.
